# RampForge AI Onboarding Builder

**From messy docs to new-hire ramp plans.**

RampForge is a hackathon MVP that turns trusted company source material into a structured, role-specific onboarding course. A manager creates a project, adds pasted docs or `.txt` / `.md` files, and runs a source-grounded generation pipeline that creates objectives, modules, lessons, quizzes, tasks, and citations.

## What is real

- The generation pipeline calls a real OpenAI-compatible LLM API via the `openai` SDK.
- It does **not** ship fake generated courses or mock AI output.
- If `OPENAI_API_KEY` is missing, generation is disabled and the UI explains how to configure it.
- Sample materials are only raw source inputs. Any course based on them must be generated by the real LLM pipeline.

## Install

```bash
npm install
```

## Configure environment

Create `.env.local` from `.env.example`:

```bash
cp .env.example .env.local
```

Example `.env.local`:

```bash
# IBM Bob open source API / OpenAI-compatible endpoint
OPENAI_API_KEY=your_real_key_here
OPENAI_BASE_URL=https://your-bob-openai-compatible-endpoint.example/v1
OPENAI_MODEL=gpt-4.1-mini
OPENAI_EMBEDDING_MODEL=text-embedding-3-small
```

`OPENAI_BASE_URL` is optional for the default OpenAI endpoint, but should be set when using the IBM Bob open-source/OpenAI-compatible API. Generation requires a real LLM API key.

## Run locally

```bash
npm run dev
```

Open http://localhost:3000.

## Demo flow

1. Create an onboarding project with name, audience, and goal.
2. Add source material by pasting text, uploading `.txt` / `.md`, or loading clearly labeled sample source materials.
3. Run the real LLM pipeline.
4. Inspect transformation artifacts: chunks, extracted objectives, deduped objectives, course modules, generated lessons, support warnings, and citations.
5. Edit lessons in manager review and approve/publish.
6. View the learner course path with progress, checkpoints, tasks, and optional citations.

## Pipeline functions

The implementation isolates the requested pipeline in `lib/pipeline.ts`:

- `ingestSources()`
- `chunkSources()`
- `extractObjectivesWithLLM()`
- `dedupeObjectives()`
- `buildCourseOutlineWithLLM()`
- `retrieveEvidenceChunks()`
- `generateLessonsWithLLM()`

LlamaIndex can be integrated later around document loading, node parsing, embeddings, and retrieval. This MVP uses manual heading/paragraph chunking and deterministic objective dedupe, while all generative steps require real LLM calls.

## Limitations

- Uses in-browser state for demo simplicity; there is no production database.
- File uploads are limited to `.txt` and `.md`.
- PDF/URL ingestion and YouTube transcript fetching are not implemented.
- Embedding-based dedupe is left as a future enhancement; current dedupe uses deterministic string similarity on real LLM-extracted objectives.
- Lesson editing is local to the page session.
